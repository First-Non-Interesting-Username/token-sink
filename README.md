# token-sink

A Linux-only CLI application that launches a locally hosted web UI for
coordinating multiple AI agents that discover, validate, document, and report
security vulnerabilities for authorized submission to the
[Hack Club Security](https://security.hackclub.com/) program.

**Status:** project skeleton only — see [PLAN.md](PLAN.md) for the full
implementation plan (architecture, safety controls, acceptance criteria).

Operating principle: research **only** assets and behavior that are explicitly
in scope and authorized. Correctness, safe testing, reproducibility, and human
review take priority over volume.
